bookmaker

Turn a PDF into a print-ready booklet, imposed into pliegos (signatures) you can fold, stack, and bind into a book.

// runs entirely in your browser — the file never leaves your device

01 input

drop a PDF here

— or —

no file selected

02 options

pages per pliego

each pliego = 4 folded sheet(s)

sheet size

double-width sheet (e.g. A4 → A3 landscape); pages stay full size

03 output

    ↓ download imposed PDF
    how to print & bind
    1. print double-sided (flip on the short edge)
    2. keep sheets in order — every 4 sheets = one pliego
    3. fold each pliego in half
    4. stack the pliegos in order and bind the spine (staple, sew, or glue)

    built with pdf-lib · everything runs client-side
